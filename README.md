# 📚 Study Tutor Agent

A simple AI Study Tutor built with:

- Streamlit
- CrewAI
- Groq
- GPT-OSS-120B
- CrewAI Memory
- Custom Tools

## Features

- Topic explanations
- Question answering
- Quiz generation
- Study planning
- Student-level adaptation
- Persistent agent memory
- Calculator tool
- Study planner tool
